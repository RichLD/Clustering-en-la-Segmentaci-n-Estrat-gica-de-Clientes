# Clustering-en-la-Segmentacion-Estrategica-de-Clientes

Este proyecto aplica técnicas avanzadas de Machine Learning No Supervisado para resolver la ineficiencia en la segmentación de lealtad de una aerolínea. Al romper con las estrategias de marketing genéricas, este modelo identifica el comportamiento real de los usuarios para permitir campañas personalizadas y optimizar la retención y el valor de vida del cliente (CLV).
